# TrackUtang

An offline, privacy-first Android debt tracker for money you lend or borrow. It stores all debt and payment information in the device's local database—there is no login or account.

## Open it in Android Studio

1. Open Android Studio and choose **Open**.
2. Select the `D:\TrackUtang` folder.
3. Let Gradle sync, then run the `app` configuration on an Android device or emulator.

## Included

- Animated branded splash screen with the TrackUtang wallet logo
- A dashboard banner with outstanding, lent, borrowed, collected and paid totals
- Separate Home, Lent, Borrowed, Profile, and Settings navigation tabs
- Debt records with name, optional contact, category, due date, notes, and status
- Partial/full payments plus a per-debt payment history and automatic balances
- Local-only profile, privacy policy, data policy, and disclaimer screens
- A clear Delete All Data control for all on-device debt records

## Current scope

The first release is designed to be fully offline. Due dates are stored and shown, but scheduled notifications, biometric/PIN lock, backup/restore, and CSV/Excel/PDF export are presented in Settings as planned capabilities and are not enabled yet. Do not publish claims that those functions are active until they are implemented and tested.
